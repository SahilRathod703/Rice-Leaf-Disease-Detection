# 🌾 Rice Leaf Disease Detection

Deep learning pipeline to classify rice leaf diseases using MobileNetV2 transfer learning.

## Results
| Model | Accuracy |
|-------|----------|
| Custom CNN | 26.09% |
| EfficientNetB0 | 34.00% |
| ResNet50 | 18.00% |
| SVM | 62.50% |
| Random Forest | 75.00% |
| **MobileNetV2** ⭐ | **91.30%** |
